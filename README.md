# Автообновление модов сервера DayZ

- Перед каждым запуском сервера скрипты скачивают свежие версии модов мастерской через **SteamCMD**, копируют их в папку сервера и кладут ключи в `keys`.
- Пока сервер работает, фоновый скрипт **раз в 15 минут** проверяет, не вышло ли обновление модов. Если вышло, он объявляет **рестарт через час** (в Discord и игрокам в чат) и перезапускает сервер. При перезапуске моды обновляются.
- **Плановый рестарт раз в 12 часов** с предупреждениями игрокам. Если плановый рестарт и так будет раньше, чем через час, отдельного рестарта для обновления нет: моды обновятся на плановом.
- В Discord приходит сообщение о вышедшем обновлении и о том, какие моды установились.

## Файлы

| Файл | Что это |
|---|---|
| `start_server.bat` | **запускайте его**: обновляет моды, запускает сервер, перезапускает после рестарта и запускает слежение за обновлениями |
| `config.bat` | **ваши настройки** (создаётся из `config.example.bat` при первом запуске). На GitHub не попадает |
| `mods.txt` | список модов: ID из мастерской и имя папки |
| `update_mods.bat` | только обновить моды (вызывается сам) |
| `watch_updates.ps1` | фоновая проверка обновлений и рестарты (запускается сам, свёрнутым окном) |
| `notify_discord.ps1` | сообщение в Discord о том, какие моды установились (вызывается сам) |

## Настройка (один раз)

1. **SteamCMD.** Скачайте (developer.valvesoftware.com/wiki/SteamCMD) и распакуйте в `C:\steamcmd`. Запустите `steamcmd.exe`, введите `login ваш_логин`, пароль и код Steam Guard, затем `quit`. Вход запомнится, пароль в файлах не хранится.
   На аккаунте **должен быть DayZ**: без него мастерская моды не отдаёт. Подойдёт основной аккаунт владельца сервера или отдельный, с купленным DayZ.
2. Запустите `start_server.bat`. Он создаст `config.bat` и остановится. Откройте `config.bat` и впишите: путь к SteamCMD, логин, папку сервера, порт.
3. В `mods.txt` перечислите моды. CF — первым.
4. **RCon** (нужен, чтобы предупреждать игроков в чате и выключать сервер правильно, с сохранением). В папке сервера откройте `battleye\BEServer_x64.cfg` (если файла нет, создайте) и впишите:
   ```
   RConPassword придумайте_длинный_пароль
   RConPort 2310
   RestrictRCon 0
   ```
   Те же порт и пароль впишите в `config.bat` (`RCON_PORT`, `RCON_PASSWORD`). Порт RCon **не открывайте** в роутере и фаерволе: скрипт подключается к нему с того же компьютера.
   Без RCon всё тоже работает, но игроков в чате никто не предупредит, а сервер будет закрываться как окно.
5. **Discord** (необязательно). В канале откройте «Настройки канала → Интеграции → Вебхуки → Новый вебхук», скопируйте URL и вставьте в `DISCORD_WEBHOOK` в `config.bat`.

Если у вас плановые рестарты уже настроены через `messages.xml` или панель хостинга, поставьте `SCRIPT_RESTARTS=0`. Тогда скрипт сам рестарты делать не будет, но будет знать о них (`RESTART_HOURS`) и не станет делать лишний рестарт перед плановым.

## Как это работает

1. `start_server.bat` → `update_mods.bat` скачивает моды → сервер запускается.
2. `watch_updates.ps1` каждые `CHECK_MINUTES` (15) минут сравнивает время версии каждого мода в мастерской Steam с тем, что скачано.
3. Вышло обновление:
   - если до планового рестарта больше `UPDATE_RESTART_DELAY` (60) минут: в Discord уходит «Вышло обновление модов… Рестарт в 15:40», игроки получают в чат «Рестарт сервера через 60 / 30 / 15 / 10 / 5 / 3 / 1 мин», затем сервер выключается командой `#shutdown`;
   - если плановый рестарт раньше, в Discord уходит «Установится на плановом рестарте в 15:10».
4. Плановый рестарт: через `RESTART_HOURS` (12) часов работы сервера, с такими же предупреждениями за 60 минут.
5. Сервер выключился → `start_server.bat` через 10 секунд снова обновляет моды (в Discord приходит, какие установились) и запускает сервер.

Журнал слежения пишется в `watch_updates.log`.

Игрокам мастерская обновляет моды сама. Если сервер обновился, а у игрока ещё старая версия, его не пустит: пусть перезапустит Steam или лаунчер.

## Безопасность

- Игроки файлы сервера не видят. `config.bat` видят только те, у кого есть доступ к самому компьютеру сервера.
- `config.bat` в `.gitignore`: даже если вы загружаете папку в этот репозиторий, логин, вебхук и пароль RCon туда не попадут.
- Пароль Steam нигде не записан. SteamCMD хранит токен входа в `C:\steamcmd\config`: доступ к компьютеру сервера = доступ к аккаунту. Включите Steam Guard в мобильном приложении. Если сервер на чужом компьютере, используйте не основной аккаунт.
- Утёк вебхук: удалите его в Discord и создайте новый.
