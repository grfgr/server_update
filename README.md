# Автообновление модов сервера

Скрипты скачивают свежие версии модов мастерской через **SteamCMD**, копируют их в папку сервера и кладут ключи в `keys`. `start_server.bat` делает это перед каждым запуском (и после каждого рестарта).

## Один раз
1. Скачайте **SteamCMD** (developer.valvesoftware.com/wiki/SteamCMD), распакуйте в `C:\steamcmd`.
2. Запустите `C:\steamcmd\steamcmd.exe`, введите `login ваш_логин`, пароль и код Steam Guard. Логин запомнится, дальше вход без пароля. Аккаунт должен владеть DayZ (анонимно моды DayZ не качаются). Лучше отдельный аккаунт для сервера.
3. В `update_mods.bat` и `start_server.bat` поправьте блок «НАСТРОЙКИ»: путь к SteamCMD, логин, папку сервера.
4. В `mods.txt` перечислите моды: ID из ссылки на мод и имя папки. CF — первым.
5. (Необязательно) Уведомления в Discord: в канале Discord откройте «Настройки канала → Интеграции → Вебхуки → Новый вебхук», скопируйте URL и впишите его в `DISCORD_WEBHOOK` в `update_mods.bat`. Не выкладывайте файл с URL вебхука в публичный репозиторий: по нему кто угодно сможет писать в канал.

## Уведомления в Discord
Если задан `DISCORD_WEBHOOK`, после обновления в канал приходит сообщение со списком модов, которые реально изменились: название из мастерской, ссылка и дата версии. Если ничего не обновилось, сообщения нет. При первом запуске все моды придут как «установлен». Отправляет `notify_discord.ps1` (вызывается сам, PowerShell есть в Windows). Ошибка Discord запуск сервера не останавливает.

## Каждый раз
- `start_server.bat` — обновить моды и запустить сервер (с автоперезапуском).
- `update_mods.bat` — только обновить моды.

Игрокам мастерская обновляет моды сама. Если сервер обновился, а у игрока ещё старая версия, его не пустит — пусть перезапустит Steam / лаунчер.
